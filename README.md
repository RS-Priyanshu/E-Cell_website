<h1>E-Cell IIMT University — Official Web Portal</h1>

<p><strong>"You Come Together, Work Together & Grow Together"</strong></p>

<p>The official web platform for the Entrepreneurship Cell (E-Cell) at IIMT University, Meerut. E-Cell is a student-led platform committed to promoting entrepreneurial thinking, providing seed mentorship, organizing startup bootcamps, and assisting students in transitioning innovative concepts into sustainable business ventures.</p>

<hr>

<h2>OVERVIEW</h2>

<p>This repository contains the front-end source code for the E-Cell IIMT University website. The portal serves as a unified digital touchpoint for university students, incubators, alumni founders, and industry leaders to collaborate, track upcoming events, and access incubation resources.</p>

<hr>

<h2>KEY FEATURES</h2>

<ul>
  <li><strong>Modern Dark Theme Interface:</strong> Designed with custom particle backgrounds, high-contrast typography, and full responsiveness across devices.</li>
  <li><strong>Performance Metrics:</strong> Dedicated section highlighting milestone data including 10,000+ social reach, 5,000+ active students, 10+ incubated startups, and multiple national competition achievements.</li>
  <li><strong>Core Initiatives:</strong>
    <ul>
      <li>Event Management: Hackathons, internal pitch competitions, and startup showcases.</li>
      <li>Leadership Seminars: Interactive sessions with startup founders, venture builders, and technical mentors.</li>
      <li>Venture Mentorship: Business plan vetting, market research guidance, and incubation bridge programs.</li>
      <li>Student Ideation Labs: Focused roundtables and brainstorming sessions.</li>
      <li>Practical Skill Workshops: Hands-on bootcamps covering venture building and tech execution.</li>
    </ul>
  </li>
  <li><strong>Network & Ecosystem:</strong> Highlights collaborations across regional and national entrepreneurship ecosystems.</li>
  <li><strong>Mentor Directory:</strong> Profiles and guidance from faculty directors, incubation managers, and external advisors.</li>
  <li><strong>Interactive Utilities:</strong> Dynamic visitor count tracking and direct social connectivity links.</li>
</ul>

LOCAL SETUP AND USAGE

Prerequisites:
A modern web browser (Google Chrome, Mozilla Firefox, Brave, or Microsoft Edge).

Installation Steps:

1. Clone the repository:
   git clone https://github.com/<your-username>/<repo-name>.git

2. Navigate into the project folder:
   cd <repo-name>

3. Launch the portal:
   - Double-click index.html to launch it directly in your browser, or
   - Serve it via VS Code using the Live Server extension by right-clicking index.html and selecting Open with Live Server.
